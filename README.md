# spiderweb_shooter
Real time hand-tracking AR effects using Python
## 🛠️ Dependencies
To run this project, you will need to install the following Python libraries:
* `opencv-python`
* `mediapipe`

## 🚀 How to Run
1. Open your terminal or command prompt.
2. Navigate into the project folder: `cd spiderweb`
3. Run the main script: `python main.py` (replace 'main.py' with your actual file name!)
